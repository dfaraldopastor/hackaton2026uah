01. Teoría — Listar archivos ocultos

El comando ls muestra el contenido de un directorio, pero por defecto esconde todo lo que empieza por un punto. En Linux, esos ficheros (.bashrc, .flag) son archivos ocultos, y suelen ser justo los que te interesan.

Combina dos flags para verlo todo: -a incluye los ocultos y -l muestra el formato largo con permisos, propietario y tamaño.

bash — 80×24 
user@shellacademy:~/sala1$ ls
notas.txt  practica

user@shellacademy:~/sala1$ ls -la
total 16
drwxr-xr-x 3 user user 4096 sep 18 09:12 .
drwxr-xr-x 8 user user 4096 sep 18 09:10 ..
-rw------- 1 user user   33 sep 18 09:12 .flag
-rw-r--r-- 1 user user   84 sep 18 09:11 notas.txt
drwxr-xr-x 2 user user 4096 sep 18 09:11 practica

TIP

Una vez localizado el fichero oculto, léelo con cat .flag para obtener la flag de este reto.
